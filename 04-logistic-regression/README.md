# Logistic Regression

## Overview
This project covers Logistic Regression, a supervised machine learning algorithm commonly used for classification.

## Topics
- Understanding classification
- Preparing features and target labels
- Training a Logistic Regression model
- Making class predictions
- Evaluating classification results

## Tools
Python, Pandas, and Scikit-learn.
