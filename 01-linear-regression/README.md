# House Price Prediction — Linear Regression

## Overview

This project demonstrates a basic Machine Learning workflow using Linear Regression to analyze housing data and predict house prices.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset

The project uses `dataset.csv`, which contains housing-related data for analysis and model building.

## Project Workflow

1. Load the dataset using Pandas.
2. Explore the dataset using `info()`, `head()`, and `describe()`.
3. Analyze categorical features such as city.
4. Prepare the data for Machine Learning.
5. Train a Linear Regression model.
6. Evaluate predictions.

## How to Run

1. Open `main.ipynb` in VS Code or Jupyter Notebook.
2. Ensure the required Python libraries are installed.
3. Run the notebook cells in order.
